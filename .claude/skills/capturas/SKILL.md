# Revisar capturas de interfaz

- Si **Comandos** de `CLAUDE.md` no tiene el comando que necesitás, preguntá al usuario y, con su respuesta, proponé agregarlo ahí. No lo inventes.
- Leé la spec, las tareas y la sección **Comandos** de `CLAUDE.md`.
- Sacá de los criterios de aceptación la lista de pantallas, estados, tamaños y condiciones que hay que mostrar.
- Regenerá las capturas con el flujo documentado en **Comandos**; no supongas que las imágenes anteriores representan el cambio actual.
- Revisá cada archivo generado, uno por uno, contra su criterio. Verificá contenido, estado, texto, recortes, navegación y errores visibles.
- Anotá el nombre de cada captura revisada y el resultado. Relacioná diferencias con el requisito correspondiente.
- Si una pantalla o estado no se puede capturar, registralo con el estado faltante y el motivo; no lo des por cubierto por una captura parecida.
- Separá capturas automáticas o simuladas de las tomadas en hardware real. No uses una como evidencia de la otra.
- Guardá el registro junto a la documentación de entrega o en la ruta de revisión existente; incluí las faltantes y diferencias pendientes.
- Si la spec no define qué mostrar o cómo juzgarlo, anotá la duda y pedí que se aclare antes de afirmar conformidad.
